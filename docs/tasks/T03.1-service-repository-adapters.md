# T03.1 - Refactor to Service + Repository + Adapters (no behavior change)

## Goal
Refactor T03 CRUD implementation into layered architecture without changing REST contract. Controller becomes thin; business rules move to service; EF access moves to repository; Entity<->DTO conversion moves to static adapters.

Prerequisite: T03 done. This task is refactor-only: same routes, same status codes, same JSON shape.

## Locked decisions
1. Full layers + `TodoResponseDto`: controller returns DTO, not EF entity.
2. Static `TodoMapper` (no DI, no AutoMapper).
3. `ITodoService` returns `TodoItem` entities; controller maps to `TodoResponseDto` via `TodoMapper`.
4. `ITodoRepository` exposes specific methods + `SaveChangesAsync`; service calls save once per operation.

## Steps
1. `DTOs/TodoDtos.cs`: ADD `TodoResponseDto {int Id, string Description, bool IsCompleted, int SortOrder, DateTime CreatedAt, DateTime UpdatedAt}`. Keep `CreateTodoDto`, `UpdateTodoDto`, `ReorderDto` unchanged.
2. Create `Adapters/TodoMapper.cs` (static class, no DI):
   - `ToResponseDto(TodoItem e) -> TodoResponseDto`
   - `ToResponseDtoList(IEnumerable<TodoItem>) -> List<TodoResponseDto>`
   - `ToEntity(CreateTodoDto dto, int sortOrder, DateTime now) -> TodoItem` (sets `Description ?? ""`, `IsCompleted=false`, timestamps)
   - `ApplyUpdate(TodoItem entity, UpdateTodoDto dto, DateTime now)` (sets `Description ?? ""`, `IsCompleted`, `UpdatedAt=now`)
3. Create `Repositories/ITodoRepository.cs`:
   ```csharp
   Task<List<TodoItem>> GetAllOrderedAsync();
   Task<TodoItem?> GetByIdAsync(int id);
   Task AddAsync(TodoItem entity);
   void Update(TodoItem entity);
   void Remove(TodoItem entity);
   Task<int> GetMaxSortOrderAsync(); // returns -1 if empty, or use nullable internally
   Task SaveChangesAsync();
   ```
   - `GetAllOrderedAsync` = `OrderBy SortOrder ThenBy Id`.
   - No `IQueryable` exposure; EF concern stays inside implementation.
4. Create `Repositories/TodoRepository.cs`: EF-only impl wrapping `TodoDbContext`. No business rules.
5. Create `Services/ITodoService.cs` (entities in/out):
   ```csharp
   Task<List<TodoItem>> GetAllAsync();
   Task<TodoItem?> GetByIdAsync(int id);
   Task<TodoItem> CreateAsync(CreateTodoDto dto);
   Task<TodoItem?> UpdateAsync(int id, UpdateTodoDto dto);
   Task ReorderAsync(List<ReorderDto> items);
   Task<bool> DeleteAsync(int id);
   ```
6. Create `Services/TodoService.cs`: move rules verbatim from T03 controller:
   - Create: `SortOrder=(MAX ?? -1)+1`, `IsCompleted=false`, `CreatedAt=UpdatedAt=UtcNow`, `Description ?? ""`. Single `SaveChangesAsync`.
   - Update: 404-style `null` if missing; else `Description ?? ""`, `IsCompleted` overwrite, `UpdatedAt=UtcNow`. Single save.
   - Reorder: per-id `SortOrder+UpdatedAt`, skip missing ids, single `SaveChangesAsync`.
   - Delete: `false` if missing; else remove + save, return `true`.
7. Slim `Controllers/TodosController.cs`: inject `ITodoService` only (no `TodoDbContext`, no `IHubContext` yet).
   - `GET /` -> `Ok(TodoMapper.ToResponseDtoList(await _service.GetAllAsync()))`
   - `GET /{id}` -> `Ok(TodoMapper.ToResponseDto(entity))` or `NotFound()`
   - `POST /` -> `CreatedAtAction(nameof(GetTodoById), new {id}, TodoMapper.ToResponseDto(created))`
   - `PUT /reorder` (BEFORE `/{id}`) -> `await _service.ReorderAsync(items); return NoContent();`
   - `PUT /{id}` -> `Ok(TodoMapper.ToResponseDto(updated))` or `NotFound()`
   - `DELETE /{id}` -> `NoContent()` or `NotFound()`
8. `Program.cs`: ADD `builder.Services.AddScoped<ITodoRepository, TodoRepository>();` + `builder.Services.AddScoped<ITodoService, TodoService>();`. Lifetimes: Scoped (matches DbContext).
9. `dotnet build backend/TodoApi` 0 errors.

## Acceptance criteria
- [ ] Builds without errors.
- [ ] GET returns ordered by `SortOrder`, shape `{id, description, isCompleted, sortOrder, createdAt, updatedAt}` camelCase unchanged.
- [ ] POST new item goes last (max+1), returns 201 `TodoResponseDto`.
- [ ] PUT updates text (even empty) and state, returns 200 `TodoResponseDto`.
- [ ] Reorder persists with single save, 204.
- [ ] DELETE 204 / 404 if missing.
- [ ] Controller has no `TodoDbContext` reference; no `new TodoItem` outside mapper/service.
- [ ] No behavior change vs T03 (frontend T05-T08 untouched).
