# T08.1 - Startup retry (backend cold-start)

## Goal
If the backend `:5000` is down when the page loads, the frontend keeps
retrying REST + SignalR automatically until it recovers (no manual reload).

## Problem
`useTodos` did one-shot `fetchTodos()` + `connection.start()`. A cold backend
left the page stuck on error + red Disconnected. `withAutomaticReconnect`
only works after a successful first `start()`, so it never recovered.

## Steps
1. `hooks/useTodos.ts`: replace one-shot load/start with `loadWithRetry()` +
   `startHubWithRetry()` loops. Exponential backoff `min(1000*2^attempt,10000)`,
   `cancelled` + timer cleanup, `setConnected('reconnecting')` while retrying,
   clear `error` on success, `reconcile()` after hub connects. `onclose` ->
   re-enter start loop (reconnect attempts exhausted). Manual `retry()` bumps
   `retrySeq` to restart both loops.
2. `App.tsx`: `Reconnecting… (retrying)` label during retries + `Retry now`
   button when `error` or not connected (calls `retry()`).
3. No contract change (REST `GET /` + `TodoChanged` shapes unchanged).

## Acceptance criteria
- [X] Backend stopped -> load `:5173` shows retrying (orange), not stuck error.
- [X] Start backend -> list loads + dot turns green with no reload.
- [X] Kill backend after connected -> orange -> green on restart.

## Validate
`npm run build` in `frontend/todo-web` + manual cold-start test above.
